# definitely-a-game

A top-down 2D action-RPG for the web. TypeScript port of [a-game-maybe](https://github.com/tehZevo/a-game-maybe) (originally Python/pygame), rebuilt to run natively in the browser and deploy via GitHub Pages.

**Play it:** https://tehzevo.github.io/definitely-a-game/

See [AGENTS.md](AGENTS.md) for build rules and project conventions.
